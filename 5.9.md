Ficha PEAS — Agente de riego automático

| Elemento                    | Descripción                                                                                                     |
| --------------------------- | --------------------------------------------------------------------------------------------------------------- |
| **Percepción (S)**          | Humedad actual del suelo y pronóstico de lluvia (`llovera_hoy`).                                                |
| **Acciones (A)**            | Regar o no regar el jardín.                                                                                     |
| **Entorno (E)**             | Jardín, suelo y condiciones climáticas.                                                                         |
| **Objetivo**                | Mantener una humedad adecuada en el suelo evitando riego innecesario.                                           |
| **Medida de desempeño (P)** | Mantener el suelo con humedad suficiente y evitar desperdiciar agua, especialmente cuando se pronostica lluvia. |

Parte B: Reglas de decisión

| Condición                         | Acción   |
| --------------------------------- | -------- |
| Humedad < 40 **y** no lloverá hoy | Regar    |
| Humedad < 40 **y** lloverá hoy    | No regar |
| Humedad ≥ 40                      | No regar |

"Se considera que el suelo está seco cuando la humedad es menor a 40. El agente solamente realizará el riego cuando el suelo esté seco y no exista lluvia pronosticada."

REFLEXION:
1. ¿Qué tan distinto fue diseñar este agente respecto al termostato? ¿A qué tipo de agente de la Sección 3.3 corresponde?
El diseño del agente de riego fue un poco más complejo que el agente termostato, debido a que debe considerar dos percepciones al mismo tiempo: la humedad del suelo y el pronóstico de lluvia. Por ello, las reglas de decisión requieren combinar condiciones para determinar si es conveniente realizar el riego.

Este agente corresponde a un agente reactivo simple, ya que toma una decisión utilizando únicamente las percepciones actuales y reglas previamente definidas, sin almacenar información de estados anteriores.
